Firmware & Embedded Architecture

Reliability in orbital environments requires rigorous low-level hardware-software codesign. My responsibilities spanned across multiple layers of the embedded stack:

  • Developed custom software drivers for TI MSP430-family microcontroller chips.
  • Wrote high-speed HDL firmware for Xilinx Zynq FPGAs to handle real-time signal processing and telemetry.
  • Coded low-level Linux drivers in C, interfacing directly with hardware peripherals via UART, JTAG, and Spy-Bi-Wire (SBW) protocols.

Automated Physical Testing & Scripting

To satisfy stringent customer specifications and aerospace standards, manual testing is insufficient. I built robust test infrastructure:

  • Created automated physical testing capabilities driven by customer specifications utilizing COSMOS serial interfaces.
  • Wrote extensive test APIs and networking logic using Python socket programming.
  • Authored high-level Bash scripts and Ruby automation scripts to streamline radio calibration and environmental stress testing pipelines.

Commercial Impact

By contributing directly to the full development cycle of modular Nanocom SDRs, the engineering team delivered flexible, resilient communications hardware that directly enabled over $10 million in new contracts signed with defense agencies and commercial satellite operators.
